# Task Manager with API Integration & Async JavaScript Practice

A comprehensive web application built according to modern JavaScript standards, demonstrating asynchronous execution, DOM manipulation, and JSONPlaceholder API integration.

---

##  Features & Assignment Implementation

1. **Task 1: Asynchronous JavaScript Practice**
   - Interactive UI cards demonstrating Execution Context, Event Loop order (`Sync vs Async`), `setTimeout()`, `setInterval()` countdown timer, Callback functions, Promises (`resolve`/`reject`), and `async/await` syntax.

2. **Task 2: Task Manager App (CRUD & LocalStorage)**
   - Add new tasks with input validation.
   - Dynamic rendering with total, completed, and pending stats counters.
   - Mark tasks as completed or delete individual items.
   - Persistent storage using browser `LocalStorage`.

3. **Task 3 & 4: API Integration & Dynamic Rendering**
   - Fetches live todo items from the JSONPlaceholder API (`https://jsonplaceholder.typicode.com/todos`).
   - Implements `async/await` with robust `try/catch` error handling.
   - Displays loading spinners and error states.
   - Dynamic filtering buttons (`All`, `Pending`, `Completed`) and search functionality.

---

##  How to Run Locally

1. Download and extract the project files.
2. Open `index.html` directly in any modern browser (Google Chrome, Edge, Firefox, Safari).
3. No build tools or backend setup required!
